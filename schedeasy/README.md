# SchedEasy – UNC Class Schedule Organizer

This is a browser-based schedule organizer. Students enter the subject details and the schedule exactly as written on their matriculation form; the page turns it into a weekly timetable.

## Publish it for other students (GitHub Pages)

1. Create a free GitHub account at https://github.com.
2. Click **New repository** and name it `schedeasy-unc`.
3. Choose **Public**, then click **Create repository**.
4. Click **Add file → Upload files**.
5. Open this `schedeasy` folder and upload all its contents: `index.html`, `styles.css`, `app.js`, and the entire `assets` folder.
6. Click **Commit changes**.
7. Open the repository's **Settings → Pages**.
8. Under **Build and deployment**, choose **Deploy from a branch**. Select `main` and the `/ (root)` folder, then click **Save**.
9. Wait one to two minutes. GitHub will show a public link similar to `https://your-username.github.io/schedeasy-unc/`.
10. Send that link to other UNC students.

Each student uses the site independently. Their classes are saved only in their own browser and are not visible to you or other students.
